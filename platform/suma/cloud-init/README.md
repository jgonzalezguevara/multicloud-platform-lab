# SUSE Multi-Linux Manager cloud-init

The SUSE Multi-Linux Manager appliance is bootstrapped through the
Proxmox cloud-init/NoCloud integration.

Custom cloud-init content is intentionally limited to user-data.yaml.

OpenTofu and the Proxmox provider generate the remaining NoCloud data.

    IPv4 address: 10.20.0.31/24
    Gateway:      10.20.0.1

Network configuration is declared through initialization.ip_config.

This avoids coupling the deployment to a guest interface name such as
eth0, ens18, or enpXsY.

Metadata is generated by Proxmox. A custom meta-data file is not
required.

The SSH public key is injected at deployment time by OpenTofu and is
not stored directly in this cloud-init template.
